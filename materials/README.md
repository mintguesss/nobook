# 教材

把上課用的 PDF / PPTX 放在**課程自己的資料夾**底下：

```
materials/
├── 生產與作業管理/      ← 課名（courses/*.yaml 的 name）
│   └── week1.pdf
└── pom-2026/          ← 或用課程代號，兩個都認
    └── week1.pptx
```

放在這一層（沒有分資料夾）的檔案會被列成「未分類」，**不會拿來對照** —— 
攤平的話每堂課都會去比對所有教材，會對到別門課的投影片。

支援 `.pdf` 與 `.pptx`。PPTX 連講者備忘稿也會讀進去。

這個資料夾的內容不進版控（是老師的東西）。
